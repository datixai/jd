# Remix plan

Ideas taken from three well designed travel sites. Only layout and interaction patterns are reused; all copy, brand, colours and media are new.

| Reference idea | Source | Travel with JD version |
| --- | --- | --- |
| Full screen video hero, transparent nav that turns solid on scroll | Audley, Black Tomato | Hero with JD's video (or a drawn mountain scene until media arrives), Roman Urdu tagline, WhatsApp CTA |
| Short "feeling" intro block | Black Tomato | "Apni wadiyan, apne log": why families from abroad travel with JD |
| Tabbed destinations (destinations / themes) | Audley | Tabs: Azad Kashmir, Gilgit-Baltistan, Khyber Pakhtunkhwa, each with place cards |
| Horizontal trip carousel with duration chips | Intrepid | Trip cards: days, region, highlights, "Ask for price" |
| Four value tiles ("what sets us apart") | Intrepid | Made for UK and overseas families: airport pickup, family vans, halal food, elders and kids friendly |
| Pickup map strip | new | Pickup points: Kotli, Khuiratta, Dadyal, Mirpur, Islamabad and Sialkot airports |
| Media gallery | new | Auto gallery from `public/media/gallery` (JD's Instagram photos and videos) |
| How it works steps | Audley "why us" | 4 steps from message to trip |
| FAQ accordion | new | Questions UK families ask |
| CTA band + enquiry | Black Tomato, Audley | Enquiry form that opens WhatsApp with a ready message |
| Dark footer | all three | Socials, flags (Kashmir, Pakistan, UK), Developed by Datix AI |
