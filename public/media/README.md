# JD's photos and videos

Drop JD's own photos and videos here, then run `npm run build` again. Missing files fall back to drawn scenes.

- `hero.mp4` (and optional `hero.jpg` poster): big video at the top of the page. Landscape, 1080p or higher, under 15 MB.
- `gallery/`: any number of `.jpg`, `.png`, `.webp`, `.mp4` files. They appear in the "Moments from our trips" gallery in file name order.
- `places/`: neelum.jpg, banjosa.jpg, tolipir.jpg, leepa.jpg, hunza.jpg, skardu.jpg, naltar.jpg, fairymeadows.jpg, kalam.jpg, malamjabba.jpg, naran.jpg, nathiagali.jpg
- `trips/`: neelum.jpg, poonch.jpg, hunza.jpg, swat.jpg, naran.jpg

Use the highest quality originals JD has (straight from his phone). Instagram itself stores photos at about 1080px wide, so originals from the phone look much sharper than downloads.
